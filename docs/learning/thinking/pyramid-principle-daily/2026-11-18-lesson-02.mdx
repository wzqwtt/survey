上一课我们练习：先把结论说清楚，再给出支撑这个结论的理由。  
今天再进一步：在同一轮表达里，只立一个总观点。

本课的生活案例与练习均为原创虚构，不是原书案例，也不是真实事件。

## 为什么只立一个总观点

Barbara Minto 官网首页说明：把想法组织成一个金字塔，并且顶上只有一个总观点，读者更容易抓住思路。  
向别人表达时，你要带读者从金字塔顶端往下走。

概念页进一步说明：充分整理后，思考会收成一座金字塔，由一个总观点统领。  
表达时带读者从顶端往下走即可。

若一条消息里有两个互不相关的判断，读者就不知道要先接住哪一个总观点。  
并列的理由可以有几条，但它们必须共同支撑同一个顶端判断。

若两件事真的同属一个更高的判断，先写出那个真正的总观点，不要用「还有一件事」硬接。  
若两件事互不相关，就分开写，不要捆在一座假金字塔下。

今天只练「一个总观点」。  
读者问题、分组检查等留到后续课。

<CollapsiblePanel title="适用边界">
  <p>这一课只教「一个总观点」，不是完整方法。</p>
  <ul>
    <li>官网把该方法用于你向读者提供思考的文件，例如邮件、备忘录、报告和幻灯片。</li>
    <li>「一个总观点」指这一轮论证或这一条消息里要读者先接住的那个判断，不是要求所有场合只能说一件事。</li>
    <li>「一个总观点」不是禁止一篇里出现并列理由；并列理由必须共同支撑顶端那一个判断。</li>
    <li>若两件事确实同属一个更高的判断，应该先写出那个真正的总观点，而不是用「还有一件事」硬接。</li>
    <li>若两件事互不相关，分开写，不要为了省事绑在一座假金字塔下。</li>
    <li>一个总观点不能代替可靠的理由和事实。</li>
    <li>完整方法还包括读者问题、分组检查、问题界定和行动建议等，留到后续课。</li>
    <li>中文课文只借鉴 ASD-STE100 的简明写法，不是该标准的认证文本。</li>
  </ul>
