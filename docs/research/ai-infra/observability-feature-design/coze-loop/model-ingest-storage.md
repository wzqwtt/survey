# coze-loop · 模型、采集与存储

本页覆盖：Trace 模型、采集入口、鉴权限流、存储与保留。每条事实链到固定提交（`3a6a2bf0`）。回到 [coze-loop 总览](index.md)。

## 一、Trace / Span 模型、类型、状态、树、token 与成本

- IDL 里的 `Trace` 只有 `trace_id`、`tokens`、`size` 三个可选字段（[idl/thrift/coze/loop/observability/domain/trace.thrift L3-L11](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/idl/thrift/coze/loop/observability/domain/trace.thrift#L3-L11)）。
- 存储和查询的主对象是 `Span`，`TraceID` 只是 span 上的字段（[backend/modules/observability/domain/trace/entity/loop_span/span.go L156-L162](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/domain/trace/entity/loop_span/span.go#L156-L162)）。
- 没有独立的 Trace 表。span 存在 `observability_spans`（[release/deployment/docker-compose/bootstrap/clickhouse-init/init-sql/observability_spans.sql L1-L36](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/release/deployment/docker-compose/bootstrap/clickhouse-init/init-sql/observability_spans.sql#L1-L36)）。
- 对外 `OutputSpan` 带 `trace_id`、`span_id`、`parent_id`、`span_name`、`span_type`、时间、状态、input、output 和各类标签（[idl/thrift/coze/loop/observability/domain/span.thrift L45-L77](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/idl/thrift/coze/loop/observability/domain/span.thrift#L45-L77)）。
- 写入用的 `InputSpan` 要求 `trace_id`、`span_id`、`parent_id`、`started_at_micros`、`duration`、`workspace_id`、input、output（[idl/thrift/coze/loop/observability/domain/span.thrift L80-L96](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/idl/thrift/coze/loop/observability/domain/span.thrift#L80-L96)）。
- 后端 span 类型常量有 `prompt`、`model`、`parser`、`embedding`、`memory`、`plugin`、`function`、`graph`、`remote`、`loader`、`transformer`、`vector_store`、`vector_retriever`、`agent`、`tool`、`LLMCall`（[backend/modules/observability/domain/trace/entity/loop_span/span.go L65-L80](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/domain/trace/entity/loop_span/span.go#L65-L80)）。
- 状态只有 `success` 和 `error` 两个常量，`status_code == 0` 映射为 `success`（[backend/modules/observability/domain/trace/entity/loop_span/span.go L82-L83](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/domain/trace/entity/loop_span/span.go#L82-L83)、[backend/modules/observability/domain/trace/entity/loop_span/span.go L386-L390](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/domain/trace/entity/loop_span/span.go#L386-L390)）。
- IDL 的状态枚举里另有 `broken`（[idl/thrift/coze/loop/observability/domain/span.thrift L6-L8](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/idl/thrift/coze/loop/observability/domain/span.thrift#L6-L8)）。
- 父子关系靠 `parent_id`，Coze Loop 列表把 `parent_id` 为 `"0"` 或空串的 span 当 root（[backend/modules/observability/domain/trace/service/trace/span_filter/cozeloop_filter.go L33-L41](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/domain/trace/service/trace/span_filter/cozeloop_filter.go#L33-L41)）。
- 详情页前端按 `span_id` 去重、按开始时间排序，再用 `parent_id` 组树（[frontend/packages/loop-components/observation-components/src/features/trace-detail/utils/span.tsx L18-L70](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/frontend/packages/loop-components/observation-components/src/features/trace-detail/utils/span.tsx#L18-L70)）。
- 父节点不在当前集合时，该 span 在前端成为根（[frontend/packages/loop-components/observation-components/src/features/trace-detail/utils/span.tsx L46-L57](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/frontend/packages/loop-components/observation-components/src/features/trace-detail/utils/span.tsx#L46-L57)）。
- `GetTrace` 按 `trace_id` 或 `logid` 取一组 span，按开始时间升序返回（[backend/modules/observability/domain/trace/service/trace_service.go L1255-L1344](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/domain/trace/service/trace_service.go#L1255-L1344)）。
- 后端另有 `SearchTraceTree`，走 `GetTraceAll`，累计上限 10 万条 span（[backend/modules/observability/domain/trace/service/trace_service.go L1350-L1390](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/domain/trace/service/trace_service.go#L1350-L1390)、[backend/modules/observability/domain/trace/service/trace_service.go L59-L62](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/domain/trace/service/trace_service.go#L59-L62)）。
- token 只统计 `span_type` 为 `LLMCall` 或 `model` 的 span，读取 `input_tokens` 和 `output_tokens` 标签（[backend/modules/observability/domain/trace/entity/loop_span/span.go L885-L929](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/domain/trace/entity/loop_span/span.go#L885-L929)）。
- Trace 级的 token 汇总由 `TraceAdvanceInfo` 提供，只有 input 和 output 两项（[idl/thrift/coze/loop/observability/coze.loop.observability.trace.thrift L55-L63](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/idl/thrift/coze/loop/observability/coze.loop.observability.trace.thrift#L55-L63)）。
- OTel 转换时，若有 `input_tokens` 或 `output_tokens` 就补算 `tokens` 总和（[backend/modules/observability/lib/otel/otel_convert.go L463-L469](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/lib/otel/otel_convert.go#L463-L469)）。
- 金额成本：无。已在 `backend/modules/observability`、`idl/thrift/coze/loop/observability`、`release/deployment/docker-compose/conf/observability.yaml` 搜索 `price`、`usd`、`currency`、`money`、`cost`，只命中 `TokenCost` 和日志耗时。

## 二、采集：OpenAPI、OTLP、SDK、MQ、collector、批量、限流、鉴权

### 入口

- OpenAPI JSON 入口是 `POST /v1/loop/traces/ingest`（[idl/thrift/coze/loop/observability/coze.loop.observability.openapi.thrift L232](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/idl/thrift/coze/loop/observability/coze.loop.observability.openapi.thrift#L232)）。
- OTLP 入口是 `POST /v1/loop/opentelemetry/v1/traces`（[idl/thrift/coze/loop/observability/coze.loop.observability.openapi.thrift L233](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/idl/thrift/coze/loop/observability/coze.loop.observability.openapi.thrift#L233)、[backend/api/router/coze/loop/apis/coze.loop.apis.go L625-L630](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/api/router/coze/loop/apis/coze.loop.apis.go#L625-L630)）。
- OTLP 先按 `Content-Encoding` 解压，再按 `Content-Type` 反序列化 protobuf 或 JSON（[backend/modules/observability/application/openapi.go L263-L274](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/application/openapi.go#L263-L274)、[backend/modules/observability/application/openapi.go L367-L388](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/application/openapi.go#L367-L388)、[backend/modules/observability/application/openapi.go L444-L461](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/application/openapi.go#L444-L461)）。
- OTLP 的 `Content-Type` 只接受包含 `application/json` 或 `application/x-protobuf` 的值（[backend/modules/observability/application/openapi.go L355-L365](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/application/openapi.go#L355-L365)）。
- OTLP 响应是 protobuf 的 `ExportTraceServiceResponse`，用 `PartialSuccess.RejectedSpans` 报告被拒数量（[backend/modules/observability/application/openapi.go L333-L352](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/application/openapi.go#L333-L352)）。
- 大字段文件用 `POST /v1/loop/files/upload` 上传（[idl/thrift/coze/loop/foundation/coze.loop.foundation.openapi.thrift L29](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/idl/thrift/coze/loop/foundation/coze.loop.foundation.openapi.thrift#L29)、[backend/api/router/coze/loop/apis/coze.loop.apis.go L622-L623](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/api/router/coze/loop/apis/coze.loop.apis.go#L622-L623)）。
- 进程内入口 `IngestTracesInner` 没有 HTTP 路由注解（[idl/thrift/coze/loop/observability/coze.loop.observability.trace.thrift L631](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/idl/thrift/coze/loop/observability/coze.loop.observability.trace.thrift#L631)）。

### SDK

- 外部 SDK 的源码不在本仓库。仓库内只能看到服务端接收它的入口。
- 平台自己用 `cozeloop-go` 客户端上报自身 span，客户端挂了自定义 exporter `MultiSpaceSpanExporter`（[backend/cmd/main.go L148-L165](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/cmd/main.go#L148-L165)）。
- `MultiSpaceSpanExporter.ExportSpans` 把 span 转成 `InputSpan`，直接调 `IngestTracesInner`（[backend/infra/looptracer/exporter.go L34-L86](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/infra/looptracer/exporter.go#L34-L86)）。
- `MultiSpaceSpanExporter.ExportFiles` 把大字段通过 `UploadLoopFileInner` 上传（[backend/infra/looptracer/exporter.go L91-L103](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/infra/looptracer/exporter.go#L91-L103)、[backend/infra/looptracer/exporter.go L105-L150](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/infra/looptracer/exporter.go#L105-L150)）。
- Prompt 调试和 PTaaS 在 span 上设置 `call_type`（[backend/modules/prompt/application/debug.go L66-L96](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/prompt/application/debug.go#L66-L96)、[backend/modules/prompt/application/openapi.go L1021](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/prompt/application/openapi.go#L1021)）。

### 校验、批量与限流

- OpenAPI 写入要求同一批 span 的 `workspace_id` 相同（[backend/modules/observability/application/openapi.go L229-L242](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/application/openapi.go#L229-L242)）。
- 单批 span 数上限按租户配置，默认配置是 100，缺配置时用常量 500（[backend/modules/observability/application/openapi.go L244-L261](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/application/openapi.go#L244-L261)、[release/deployment/docker-compose/conf/observability.yaml L1-L10](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/release/deployment/docker-compose/conf/observability.yaml#L1-L10)、[backend/modules/observability/application/trace.go L44-L51](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/application/trace.go#L44-L51)）。
- OTLP 入口没有 span 数量检查（[backend/modules/observability/application/openapi.go L355-L365](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/application/openapi.go#L355-L365)）。
- 服务端校验 `trace_id` 是 32 位小写十六进制、`span_id` 是 16 位小写十六进制，且都不能全 0（[backend/modules/observability/domain/trace/entity/loop_span/span.go L537-L556](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/domain/trace/entity/loop_span/span.go#L537-L556)）。
- `start_time` 必须落在当前时间前 24 小时到后 1 小时之间（[backend/modules/observability/domain/trace/entity/loop_span/span.go L557-L559](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/domain/trace/entity/loop_span/span.go#L557-L559)）。
- 过长字段会被裁剪，被裁字段名写入 `system_tags_string.clip_fields`（[backend/modules/observability/domain/trace/entity/loop_span/span.go L850-L882](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/domain/trace/entity/loop_span/span.go#L850-L882)）。
- 写入口 `IngestTraces` 先跑 ingest processor，再把 span 打成 `TraceData` 交给 producer（[backend/modules/observability/domain/trace/service/trace_service.go L1627-L1655](https://github.com/wzqwtt/coze-loop/blob/3a6a2bf07b057fec0c702e514e8345fb5684e83a/backend/modules/observability/domain/trace/service/trace_service.go#L1627-L1655)）。
