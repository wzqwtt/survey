# Langfuse · 模型、采集与存储

本页覆盖：Trace 模型、采集入口、鉴权限流、存储与保留。每条事实链到固定提交（`f75c661d`）。回到 [Langfuse 总览](index.md)。

## 1. Trace / Observation 模型、类型、层级、Token 与成本

### 1.1 Trace 与 Observation 的领域对象

- `TraceDomain` 是前后端共用的 Zod 对象（`packages/shared/src/domain/traces.ts` L12-L30，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/domain/traces.ts#L12-L30)）。
- Trace 字段包括 `id`、`name`、`timestamp`、`environment`、`tags`、`bookmarked`、`public`、`release`、`version`、`input`、`output`、`metadata`、`sessionId`、`userId`、`projectId`（同上范围）。
- `ObservationType` 有 `SPAN`、`EVENT`、`GENERATION`、`AGENT`、`TOOL`、`CHAIN`、`RETRIEVER`、`EVALUATOR`、`EMBEDDING`、`GUARDRAIL` 共 10 种（`packages/shared/src/domain/observations.ts` L5-L17，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/domain/observations.ts#L5-L17)）。
- `ObservationSchema` 用可空 `traceId` 指向 Trace，用可空 `parentObservationId` 指向父 Observation（`packages/shared/src/domain/observations.ts` L55-L65，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/domain/observations.ts#L55-L65)）。
- Observation 还带 `level`、`statusMessage`、模型、用量、成本、`promptId`、`promptName`、`promptVersion`、工具定义与工具调用（`packages/shared/src/domain/observations.ts` L66-L100，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/domain/observations.ts#L66-L100)）。
- `EventsObservationSchema` 在 Observation 上附加 `userId`、`sessionId`、`traceName`、`release`、`tags`、`bookmarked`、`public`、`isRootObservation`（`packages/shared/src/domain/observations.ts` L116-L125，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/domain/observations.ts#L116-L125)）。
- 根 Observation 的判定是没有 `parentObservationId`，或 `isAppRoot === true`（`packages/shared/src/eventsTable.ts` L44-L50，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/eventsTable.ts#L44-L50)）。
- 在 SQL 里，根行条件是 `parent_span_id = '' OR is_app_root = true`（`packages/shared/src/eventsTable.ts` L4-L7，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/eventsTable.ts#L4-L7)）。

### 1.2 层级

- ClickHouse `events_full` 用 `trace_id`、`span_id`、`parent_span_id` 表示同一条 Trace 里的 span 树（`packages/shared/clickhouse/migrations/canonical/0039_create_events_full.up.sql` L4-L6，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/clickhouse/migrations/canonical/0039_create_events_full.up.sql#L4-L6)）。
- 同一行带 `trace_name`、`is_app_root`、`session_id`、`user_id`、`tags`（`packages/shared/clickhouse/migrations/canonical/0039_create_events_full.up.sql` L16-L24，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/clickhouse/migrations/canonical/0039_create_events_full.up.sql#L16-L24)）。
- 从 events 聚合 Trace 时，`id` 取 `trace_id`，`timestamp` 取 `min(start_time)`（`packages/shared/src/server/queries/clickhouse-sql/event-query-builder.ts` L528-L535，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/server/queries/clickhouse-sql/event-query-builder.ts#L528-L535)）。
- Trace 的 `input`、`output`、`metadata`、`bookmarked` 取 `parent_span_id = ''` 的最新 `event_ts` 行（`packages/shared/src/server/queries/clickhouse-sql/event-query-builder.ts` L541-L558，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/server/queries/clickhouse-sql/event-query-builder.ts#L541-L558)）。
- Trace 级聚合 level 按 ERROR、WARNING、DEFAULT、DEBUG 的优先级取最高（`packages/shared/src/server/queries/clickhouse-sql/event-query-builder.ts` L566-L567，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/server/queries/clickhouse-sql/event-query-builder.ts#L566-L567)）。
- `eventsTracesAggregation` 的注释写明：按 `trace_id` 把 events 重新聚成 Trace，并称这是迁到只用 events 表之前的临时做法（`packages/shared/src/server/queries/clickhouse-sql/query-fragments.ts` L103-L128，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/server/queries/clickhouse-sql/query-fragments.ts#L103-L128)）。
- 旧 `traces` 表独立存在，初始建表使用 `ReplacingMergeTree(event_ts, is_deleted)`，按 `toYYYYMM(timestamp)` 分区（`packages/shared/clickhouse/migrations/canonical/0001_traces.up.sql` L1-L23，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/clickhouse/migrations/canonical/0001_traces.up.sql#L1-L23)）。

### 1.3 采集事件类型

- 采集事件类型包含 `trace-create`、`span-create/update`、`generation-create/update`、`event-create`、`score-create`、`sdk-log`、`dataset-run-item-create`，以及 agent、tool、chain、retriever、evaluator、embedding、guardrail 的 create（`packages/shared/src/server/ingestion/types.ts` L319-L339，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/server/ingestion/types.ts#L319-L339)）。
- `observation-create` 与 `observation-update` 被标成仅为兼容保留的旧类型（`packages/shared/src/server/ingestion/types.ts` L336-L338，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/server/ingestion/types.ts#L336-L338)）。
- Generation 在 Span 字段上增加 `model`、`usage`、`costDetails`、`promptName`、`promptVersion`（`packages/shared/src/server/ingestion/types.ts` L513-L540，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/server/ingestion/types.ts#L513-L540)）。
- `promptName` 与 `promptVersion` 必须同时出现或同时为空（`packages/shared/src/server/ingestion/types.ts` L535-L539，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/server/ingestion/types.ts#L535-L539)）。

### 1.4 模型匹配、Token 计数、成本

- 模型定义存在 Postgres `Model` 表，含 `matchPattern`、单价、`tokenizerId`、`tokenizerConfig`，可按项目覆盖（`packages/shared/prisma/schema.prisma` L912-L932，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/prisma/schema.prisma#L912-L932)）。
- 价格拆成 `Price`（按 `usageType`）和 `PricingTier`（含 `priority`、`isDefault`、`conditions`）（`packages/shared/prisma/schema.prisma` L955-L969，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/prisma/schema.prisma#L955-L969)）。
- `findModel` 先查本地缓存，再查 Redis 缓存，最后查库（`packages/shared/src/server/ingestion/modelMatch.ts` L44，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/server/ingestion/modelMatch.ts#L44)）。
- Worker 对有 `provided_model_name` 的观测调用 `findModel`，否则不匹配模型（`worker/src/services/IngestionService/index.ts` L1363，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/worker/src/services/IngestionService/index.ts#L1363)）。
- 价格档按条件匹配：条件可对 `usageDetails` 的键做正则求和比较，也可比较 `modelParameters` 或 `metadata` 的值（`packages/shared/src/server/pricing-tiers/matcher.ts` L18-L30，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/server/pricing-tiers/matcher.ts#L18-L30)）。
- Worker 调 `matchPricingTier` 选出价格档，再算成本（`worker/src/services/IngestionService/index.ts` L1411，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/worker/src/services/IngestionService/index.ts#L1411)）。
- 只有在「用户没给 usage、没给 cost、模型已匹配、level 不是 ERROR、不是 AI Gateway 生成」时才做本地 tokenize（`worker/src/services/IngestionService/index.ts` L1491-L1497，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/worker/src/services/IngestionService/index.ts#L1491-L1497)）。
- 用户给了任一成本点后，不再计算其他成本点，直接用用户提供的值（`worker/src/services/IngestionService/index.ts` L1713-L1716，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/worker/src/services/IngestionService/index.ts#L1713-L1716)）。
- 未提供成本时，按 `usageUnits` 的键逐项匹配价格并相乘（`worker/src/services/IngestionService/index.ts` L1740-L1743，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/worker/src/services/IngestionService/index.ts#L1740-L1743)）。
- 本地 tokenizer 有 `openai`（tiktoken）和 `claude` 两种（`worker/src/features/tokenisation/usage.ts` L51-L57，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/worker/src/features/tokenisation/usage.ts#L51-L57)）。
- events 路径的成本与用量按 span 做 `sum` / `sumMap` 聚合成 Trace 总量（`packages/shared/src/server/queries/clickhouse-sql/event-query-builder.ts` L549-L565，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/server/queries/clickhouse-sql/event-query-builder.ts#L549-L565)）。
- 价格档与模型管理有独立 tRPC 路由 `models`（`web/src/server/api/root.ts` L99，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/server/api/root.ts#L99)）和页面 `/project/[projectId]/models`（`web/src/pages/project/[projectId]/models.tsx` L1，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/pages/project/%5BprojectId%5D/models.tsx#L1)）。
- 公共 API 有 `/api/public/models` 目录下的路由（`web/src/pages/api/public/models/index.ts` L1，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/pages/api/public/models/index.ts#L1)）。

## 2. 采集：legacy ingestion、公共 API、OTLP、SDK、队列、批处理、限流、鉴权

### 2.1 入口

- 入口 `POST /api/public/ingestion` 接收 `{ batch, metadata }`，先做权限、限流和格式校验，再异步处理（`web/src/pages/api/public/ingestion.ts` L56-L70，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/pages/api/public/ingestion.ts#L56-L70)）。
- 请求体上限是 4.5mb（`web/src/pages/api/public/ingestion.ts` L48-L54，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/pages/api/public/ingestion.ts#L48-L54)）。
- 用量超阈值时 ingestion 被拒绝（`web/src/pages/api/public/ingestion.ts` L127，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/pages/api/public/ingestion.ts#L127)）。
- 在 `events_only` 下，该端点只接受 `score-create`（`web/src/pages/api/public/ingestion.ts` L295-L297，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/pages/api/public/ingestion.ts#L295-L297)）。
- 被拒绝的非 score 事件返回 400，并提示改用 v4 SDK 或 OTLP，或临时把写入模式设成 `dual`（`web/src/pages/api/public/ingestion.ts` L311-L345，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/pages/api/public/ingestion.ts#L311-L345)）。
- Legacy REST 还有 `POST /api/public/traces`、`spans`、`events`、`generations`；它们把 body 包成 ingestion 事件再走同一管线（`web/src/pages/api/public/traces/index.ts` L39-L64，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/pages/api/public/traces/index.ts#L39-L64)、`web/src/pages/api/public/spans.ts` L18-L38，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/pages/api/public/spans.ts#L18-L38)、`web/src/pages/api/public/events.ts` L16-L33，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/pages/api/public/events.ts#L16-L33)、`web/src/pages/api/public/generations.ts` L19-L35，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/pages/api/public/generations.ts#L19-L35)）。
- 这些 legacy 写接口在 `events_only` 下被拒绝（`web/src/pages/api/public/traces/index.ts` L45-L47，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/pages/api/public/traces/index.ts#L45-L47)）。
- OTLP 入口是 `POST /api/public/otel/v1/traces`，权限 `traces:create`，限流资源 `ingestion`（`web/src/pages/api/public/otel/v1/traces/index.ts` L26-L33，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/pages/api/public/otel/v1/traces/index.ts#L26-L33)）。
- OTLP 路由关闭 bodyParser，自行读 body，并支持 gzip（`web/src/pages/api/public/otel/v1/traces/index.ts` L20-L24，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/pages/api/public/otel/v1/traces/index.ts#L20-L24)）。
- OTLP 路由读取 `x-langfuse-ingestion-version` 头，并和 SDK 名称、版本一起交给 `processOtelIngestion`（`web/src/pages/api/public/otel/v1/traces/index.ts` L96，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/pages/api/public/otel/v1/traces/index.ts#L96)）。
- OTLP metrics 端点 `POST /api/public/otel/v1/metrics` 的处理函数是空函数 `fn: async () => {}`（`web/src/pages/api/public/otel/v1/metrics/index.ts` L18，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/pages/api/public/otel/v1/metrics/index.ts#L18)）。
- SDK 自身代码不在本仓库；仓库只读取 SDK 头（`x-langfuse-sdk-name`、`x-langfuse-sdk-version`、`x-langfuse-ingestion-version`）来决定写入路径（`worker/src/queues/otelIngestionQueue.ts` L60-L100，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/worker/src/queues/otelIngestionQueue.ts#L60-L100)）。
- 另有媒体上传入口 `POST /api/public/media`，限流资源 `media-upload`（`web/src/pages/api/public/media/index.ts` L19，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/pages/api/public/media/index.ts#L19)）。

### 2.2 鉴权与限流

- 公共 API 支持 Basic 认证（公钥加私钥，完整 scope）和 Bearer 认证（只有公钥，受限 scope）（`web/src/features/public-api/server/apiAuth.ts` L92，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/features/public-api/server/apiAuth.ts#L92)、`web/src/features/public-api/server/apiAuth.ts` L215，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/features/public-api/server/apiAuth.ts#L215)）。
- API Key 有 `PROJECT` 与 `ORGANIZATION` 两种 scope（`web/src/features/public-api/server/apiAuth.ts` L183，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/features/public-api/server/apiAuth.ts#L183)）。
- 限流用 `rate-limiter-flexible` 的 `RateLimiterRedis`，按「组织、套餐、资源」分桶（`web/src/features/public-api/server/RateLimitService.ts` L47-L50，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/features/public-api/server/RateLimitService.ts#L47-L50)）。
- 自托管和没有 Redis 时不限流（`web/src/features/public-api/server/RateLimitService.ts` L48，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/features/public-api/server/RateLimitService.ts#L48)）。
- 限流资源有 `ingestion`、`media-upload`、`public-api`、`public-api-metrics`、`public-api-v2-metrics`、`prompts`、`datasets`、`annotation-queues`、`trace-delete`、`score-delete` 等（`packages/shared/src/interfaces/rate-limits.ts` L4，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/interfaces/rate-limits.ts#L4)）。
- 限流出错时 ingestion 选择放行（fail open）（`web/src/pages/api/public/ingestion.ts` L158，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/pages/api/public/ingestion.ts#L158)）。
- score 事件要求 `scores:create`，其余事件要求 `traces:create`（`web/src/pages/api/public/ingestion.ts` L384-L390，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/pages/api/public/ingestion.ts#L384-L390)）。
