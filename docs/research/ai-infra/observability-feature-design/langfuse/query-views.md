## 4. 查询：列表、详情、树/时间线/图、过滤语法、排序分页、聚合

### 4.1 tRPC 与 v3/v4 双路径

- tRPC 根路由注册了 `traces`、`sessions`、`users`、`scores`、`models`、`events` 等（`web/src/server/api/root.ts` L77，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/server/api/root.ts#L77)、`web/src/server/api/root.ts` L90，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/server/api/root.ts#L90)）。
- 许多路由有成对的 v3 与 v4 过程：如 `sessions.all` 与 `sessions.allFromEvents`（`web/src/server/api/routers/sessions.ts` L197，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/server/api/routers/sessions.ts#L197)、`web/src/server/api/routers/sessions.ts` L260，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/server/api/routers/sessions.ts#L260)）。
- `users` 路由同样成对：`all` 与 `allFromEvents`（`web/src/server/api/routers/users.ts` L139，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/server/api/routers/users.ts#L139)）。
- `scores` 路由也有 `allFromEvents`（`web/src/server/api/routers/scores.ts` L212，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/server/api/routers/scores.ts#L212)）。
- v4 的主入口是 `events` 路由：`all`（分页）、`listCursor`（游标）、`countAll`、`filterOptions`、`metadataValues`、`byTraceId`、`getAgentGraphData` 等（`web/src/features/events/server/eventsRouter.ts` L134，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/features/events/server/eventsRouter.ts#L134)、`web/src/features/events/server/eventsRouter.ts` L215，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/features/events/server/eventsRouter.ts#L215)、`web/src/features/events/server/eventsRouter.ts` L496，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/features/events/server/eventsRouter.ts#L496)）。
- `events.all` 先应用评论过滤，再调 `getEventList`，传入 `page` 与 `limit`（`web/src/features/events/server/eventsRouter.ts` L159-L168，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/features/events/server/eventsRouter.ts#L159-L168)）。
- `events.listCursor` 固定按 `startTime DESC` 排序，用 `cursor` 翻页（`web/src/features/events/server/eventsRouter.ts` L242-L249，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/features/events/server/eventsRouter.ts#L242-L249)）。

- 该函数标了 `@deprecated`，新用途应直接用 `getTraceByIdFromEventsTable`（`packages/shared/src/server/repositories/events.ts` L1213，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/server/repositories/events.ts#L1213)）。

- `hasAnyTracingData` 先看项目的 `hasTraces` 标记，未命中再查 ClickHouse（`packages/shared/src/server/repositories/events.ts` L1300-L1312，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/server/repositories/events.ts#L1300-L1312)）。

### 4.3 过滤语法

- 过滤状态 `FilterState` 是类型化条件列表，类型包括 `datetime`、`string`、`number`、`stringOptions`、`arrayOptions`、`stringObject`、`numberObject`、`booleanObject`、`null`、`positionInTrace`（`packages/shared/src/interfaces/filters.ts` L4-L29，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/interfaces/filters.ts#L4-L29)）。
- 字符串操作符有 `=`、`contains`、`does not contain`、`starts with`、`ends with`、`is not empty`（`packages/shared/src/interfaces/filters.ts` L6-L13，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/interfaces/filters.ts#L6-L13)）。
- 数组操作符有 `any of`、`none of`、`all of`（`packages/shared/src/interfaces/filters.ts` L16，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/interfaces/filters.ts#L16)）。
- 另有全文匹配操作符 `matches`，只支持 input、output、metadata（`packages/shared/src/interfaces/filters.ts` L34，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/interfaces/filters.ts#L34)、`packages/shared/src/server/queries/clickhouse-sql/fts.ts` L16，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/server/queries/clickhouse-sql/fts.ts#L16)）。
- 过滤条件在 URL 里用竖线分隔编码，值里的竖线会被转义（`packages/shared/src/features/filters/filterQueryEncoding.ts` L26，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/features/filters/filterQueryEncoding.ts#L26)）。
- 内存过滤有 `InMemoryFilterService`，用于自动化触发条件匹配（`packages/shared/src/server/automations.ts` L34，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/packages/shared/src/server/automations.ts#L34)）。

- 前端有自然语言过滤：`naturalLanguageFilter.createCompletion`，自托管部署里不可用（`web/src/features/natural-language-filters/server/router.ts` L45，[permalink](https://github.com/wzqwtt/langfuse/blob/f75c661dbe8c6b85523c81486b39e8403ac2c141/web/src/features/natural-language-filters/server/router.ts#L45)）。
